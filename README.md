# entities-scene-room-1107

A living-room map scene in an engine project, with the addons that define it as a V-Sekai map and upload it.

## What it is for

The project's main scene is the room: a glTF model of its walls and wallpaper, a camera and a collider. Its map definition and upload pipeline come from the V-Sekai addons, most of them pinned as submodules.

## Build and run

    git submodule update --init
    godot --path .
